# 🎮 Arena Pro

**Arena Pro** is a modern gaming and esports platform designed for players to explore games, manage virtual coins, participate in tournaments, and compete for top positions on leaderboards.

Built with **React.js, Vite, and Tailwind CSS**, Arena Pro provides a fast, responsive, and engaging gaming experience with a modern esports-inspired interface.

🌐 **Live Demo:** https://arena-pro.ai.studio/

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Go to the project directory

```bash
cd arena-pro
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
